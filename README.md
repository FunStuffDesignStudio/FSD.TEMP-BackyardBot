Hyper-Local Robotic Entanglements (HLRE) is a research project that merges modern emerging technologies with ancient earthen building materials in ways that respond to and collaborate with our existing environment, enabling a site responsive and more cost-effective building process than previously explored in robotics-enabled construction-scale building. This trans-disciplinary project is both a series of participatory activations and research project, exploring community-accessible manufacturing technology using hyper local materials. 

Output: Backyard-bot is a custom robotic system that moves within a tensioned cable gantry system. This version has a gripper attached for the movement & precise arrangement of building components like earthen bricks. The lightweight cable gantry frame allows for installation between temporary tieback points and adapts to uneven ground through sensor feedback and computational path refinement.

This iteration of HLRE includes 2 public workshops sited at NATURE Lab in North-Central Troy, NY, a public repository of open-source files, and a zine series.

Hyper-Local Robotic Entanglements is a project led by FSD.TEMP that explores the design and implementation of a DIY backyard robot to build with natural materials gathered from local sources. HLRE explores how to encourage the tangibility of emerging technologies through public engagement and physical artifacts.
